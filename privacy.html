Règles de confidentialité de gta6bot

Dernière mise à jour : 21 novembre 2026.

1. Ce que fait gta6bot

gta6bot est un outil personnel. Il publie des vidéos courtes sur la chaîne YouTube de son propriétaire (Six Actu), et uniquement sur celle-ci.

2. Utilisation des services d'API YouTube

gta6bot utilise les services d'API YouTube. En utilisant gta6bot, vous acceptez d'être lié par les Conditions d'utilisation de YouTube.

Les données traitées via les services d'API YouTube le sont aussi conformément aux Règles de confidentialité de Google.

3. Informations consultées, collectées, stockées et partagées

  • Consultées : aucune donnée YouTube n'est lue. Le seul niveau d'accès demandé est youtube.upload, qui permet uniquement d'envoyer des vidéos.
  • Collectées : aucune donnée personnelle de spectateurs ou d'autres utilisateurs Google.
  • Stockées : le jeton d'accès OAuth du propriétaire, enregistré uniquement sur son ordinateur personnel, ainsi que les vidéos produites.
  • Partagées : rien. Aucune donnée n'est partagée, vendue ou transmise à des tiers.

4. TikTok et Instagram

  • TikTok : gta6bot utilise Login Kit et l'API Content Posting de TikTok avec les niveaux d'accès user.info.basic, video.upload et video.publish. Il lit uniquement les informations du compte qui l'a autorisé (identifiant, pseudo, options de confidentialité disponibles) pour publier ses vidéos. Il ne lit aucune donnée d'autres utilisateurs. Le jeton d'accès est enregistré uniquement sur l'ordinateur du propriétaire. L'accès peut être retiré à tout moment dans l'application TikTok (Paramètres → Sécurité → Applications autorisées) ; le jeton est alors supprimé sous 7 jours. Voir aussi la politique de confidentialité de TikTok.
  • Instagram : les Reels sont publiés sur le compte professionnel Six Actu via l'API Instagram de Meta. Seules les statistiques de ses propres publications (vues, portée) sont lues.
  • Aucune de ces données n'est vendue, partagée ou transmise à des tiers.

5. Cookies et appareils

gta6bot ne dépose aucun cookie et ne lit ni ne stocke aucune information sur les appareils des utilisateurs. Ce site ne contient aucun outil de suivi.

6. Retirer l'accès et supprimer les données

  • L'accès de gta6bot peut être retiré à tout moment depuis la page des paramètres de sécurité de Google (Compte Google → Sécurité → Applications tierces).
  • Une fois l'accès retiré, le jeton enregistré est supprimé de l'ordinateur du propriétaire sous 7 jours au plus tard.
  • Toute demande de suppression peut être adressée via la chaîne YouTube Six Actu ; elle est traitée sous 7 jours.

7. Contact

Pour toute question : via la chaîne YouTube Six Actu.

Privacy policy (English)

gta6bot uses YouTube API Services. By using gta6bot you agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy.

gta6bot is a personal tool that uploads short videos to its owner's YouTube channel (Six Actu) only. It requests the youtube.upload scope and reads no YouTube data. It collects no personal data from viewers or other users, stores the owner's OAuth token only on the owner's computer, and shares nothing with third parties. It sets no cookies and stores no information on users' devices. Access can be revoked at any time at Google security settings; the stored token is then deleted within 7 days.

TikTok and Instagram. gta6bot uses TikTok Login Kit and the Content Posting API (scopes user.info.basic, video.upload, video.publish). It reads only the authorising account's basic info and allowed privacy options in order to post that account's videos, reads no other users' data, and stores the access token on the owner's computer only. Access can be removed at any time in the TikTok app (Settings → Security → Authorized apps); the token is then deleted within 7 days. Instagram Reels are posted to the Six Actu professional account through Meta's Instagram API, which is also used to read that account's own post statistics. Nothing is sold or shared.
